## 🚀 Live Deployment on GitHub Pages

This repository is built with vanilla HTML5, Tailwind CSS, Lucide Icons, and lightweight JavaScript. It deploys automatically via GitHub Pages with **$0 hosting costs**.

### To Enable GitHub Pages:
1. Go to your repository settings: [github.com/jahanzaibahmad630-bit/website/settings/pages](https://github.com/jahanzaibahmad630-bit/website/settings/pages)
2. Under **Build and deployment** > **Branch**:
   - Select `main`
   - Select `/ (root)` folder
3. Click **Save**.
4. Within 60 seconds, your site will be live at:
   👉 **`https://jahanzaibahmad630-bit.github.io/website/`**
